M-A-R-I: your AI agents, working as one

An open-source framework to build, orchestrate and scale multi-agent AI systems across a distributed cluster.

AI is no longer a single model answering a single question. Real value comes from many specialised agents, each doing one thing well, that collaborate, react to events and share what they learn. Building that by hand means fighting with distribution, scheduling, state, failures and scaling, long before you write any business logic.

M-A-R-I takes care of that foundation. Built on .NET 8 and Microsoft Orleans, it gives you a proven distributed runtime and a simple, fluent way to describe how your agents work together. You focus on what your agents do; M-A-R-I makes them run, together, at scale.

Why M-A-R-I

  • Agents as virtual grains. Every agent is a lightweight virtual actor: created on demand, distributed automatically across your nodes, and never blocked by the others.
  • Orchestration without glue code. Chain agents into sequences, start them with triggers (schedules, signals or data streams) and combine signals through logical doors. Your workflow stays readable and declarative.
  • A shared memory for collaboration. The Blackboard lets agents publish, query and reason over shared data, the classic pattern for collective problem solving.
  • Bring your own AI stack. Run Python or any other program as a first-class agent, locally or inside Docker containers. Your existing models and scripts join the cluster as they are.
  • Change behaviour at runtime. Dynamic definitions and redirections let you create workflows and swap agent implementations without redeploying.
  • Built to scale. Start on a laptop, then grow to a multi-node cluster with MongoDB-backed persistence. The same code runs everywhere.

Open source, everywhere

M-A-R-I is released under the MIT licence: free to use, modify and ship in commercial products. It runs on Linux, Windows and macOS, and is distributed as NuGet packages for .NET and a Python package for external agents.

What you can build

  • Data pipelines where collectors, analysers and decision agents cooperate in real time.
  • Monitoring and automation systems that react to events and schedules across your infrastructure.
  • Hybrid AI solutions mixing .NET services, Python models and containerised tools.
  • Research platforms for meta AI: systems of agents that coordinate, evaluate and improve other agents.

Our story

M-A-R-I comes from years of work on multi-agent systems. The first version was born in 2017 in an AI lab in Brussels, created by Jerome Fortias and his friend Mickael Thumerel, and it has since grown into the framework we share today. M-A-R-I carries Micka's legacy forward, as an open tool for everyone building the next generation of distributed AI.
